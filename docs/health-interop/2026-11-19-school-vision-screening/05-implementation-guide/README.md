# School Vision Screening — Implementation Guide

Published guide:
https://josemandrade.github.io/prueba-his-muse-nvidia/school-vision-screening/

Implementation Guide (FHIR R4) for school vision screening: the school
nurse screens visual acuity, refers abnormal results to ophthalmology,
receives the assessment, notifies parents and the primary-care team, and
records teacher accommodations. Built with SUSHI (FSH) from `input/fsh/`;
20 profiles, 6 CodeSystems, 7 ValueSets, 19 examples. Validated with SUSHI
(0 errors / 0 warnings) and the FHIR IG Publisher.

## Build

- `sushi .` (needs fsh-sushi installed)
- `java -Xms3550m -Xmx3550m -jar publisher.jar -ig .` (needs Java 17 + Jekyll; in CI this
  runs in `.github/workflows/ig-build.yml`)
- The publisher output goes to `output/`; the QA report is `output/qa.tgz`.

## Contents

- `sushi-config.yaml` — guide id and canonical (the published URL above).
- `input/fsh/` — profiles, CodeSystems, ValueSets, examples.
- `input/pagecontent/` — the guide's pages (index, usecase, process,
  resources, sequences, profiles, operations, ihe, lifecycle, terminology,
  public-health, examples).
- `fsh-generated/` — resources generated by SUSHI (do not edit by hand).
