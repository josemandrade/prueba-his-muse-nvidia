# Validation - School Vision Screening Use Case

## 2026-11-19: Process Expert Review of Use Case Spec (Step 1)

### Review Findings

| ID | Severity | Finding | Proposed Correction |
|----|----------|---------|---------------------|
| C1 | High | Child absent on screening day not modeled. No re-screening path, no "missed" status, no follow-up by nurse. | Add "child absent" as a screening outcome with re-screening task and deadline (e.g., within 2 weeks). |
| C2 | High | Parent declines referral after screening not modeled. Opt-out is for screening only; a parent may refuse the referral. | Add "parent declines referral" as a terminal outcome for the referral path, with notification to primary care that referral was declined. |
| C3 | Medium | No deadline for ophthalmology assessment return. Nurse has no way to know "waiting too long". | Define expected turnaround (e.g., 4 weeks) and add escalation task for nurse if no feedback by deadline. |
| C4 | Medium | No handling of partial/uncooperative screening (e.g., one eye tested, child unable to complete). | Add "incomplete" screening outcome with re-screening or direct referral path per protocol. |
| C5 | Low | Referral letter copy retained in school file — what happens to it at year-end archive? | Clarify in data governance: referral copy archived with screening record or separate? |
| C6 | Low | Teacher accommodation notice — who generates it, when, and how is it updated if prescription changes? | Specify trigger: nurse generates accommodation note from ophthalmology feedback; updated on new feedback. |

### Questions for User Decision

| ID | Question | Impact on Model/Spec |
|----|----------|----------------------|
| Q1 | What is the protocol for a child absent on screening day? Re-screen same year? Next year? Refer to primary care? | Adds re-screening task and/or alternative referral path in BPMN. |
| Q2 | If parent declines the ophthalmology referral after screening, does primary care still receive the screening result? | Adds "referral declined" branch with primary care notification. |
| Q3 | What is the expected turnaround for ophthalmology assessment, and who escalates if it's missed? | Adds deadline boundary event and escalation task in BPMN. |
| Q4 | How is "incomplete" screening handled (child uncooperative, only one eye tested)? | Adds "incomplete" outcome with defined next step. |
| Q5 | When the ophthalmologist returns "did not attend" (DNA), does the nurse re-refer, or does it close? | Adds DNA handling branch in return path. |

### User Answers (2026-11-19)

| ID | Answer | Accepted Correction |
|----|--------|---------------------|
| Q1 | Re-screen within 2 weeks in same school year. If still absent, record as missed, notify parent. Do not refer to primary care for absence alone. | C1 resolved: add absent → re-screen (2 weeks) → missed → parent notify path. No primary care referral for absence. |
| Q2 | Yes, primary care still receives screening result, decline recorded with reason. Referral not sent. | C2 resolved: add "referral declined" branch with primary care notification of screening result + decline reason. |
| Q3 | Expected turnaround 4 weeks from referral to assessment return. If nothing in 4 weeks, nurse contacts parent, re-issues referral if lost. | C3 resolved: add 4-week deadline boundary event on referral waiting; escalation = nurse contacts parent, re-issues if needed. |
| Q4 | Record as incomplete with reason. Re-screen within 2 weeks. If still incomplete after two attempts, refer directly to ophthalmology with partial result noted. | C4 resolved: add incomplete → re-screen (2 weeks) → if 2nd incomplete, direct referral with partial data. |
| Q5 | Nurse contacts parent, offers one re-referral with new appointment. If child does not attend twice, close as DNA and notify primary care. | C5 resolved: add DNA → contact parent → one re-referral → 2nd DNA → close + primary care notify. |
| C5 (Low) | Referral letter copy retained with screening record for school year, then archived together. | Accepted: clarify in data governance. |
| C6 (Low) | Teacher accommodation notice generated by nurse from ophthalmology feedback when received. | Accepted: specify trigger in design note. |

**PASSED** — All critical/high findings resolved with user-accepted corrections. Medium findings resolved. Low findings clarified. Spec updated below.
