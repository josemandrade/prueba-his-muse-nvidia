# Derivación APS → especialidad con contrareferencia — Implementation Guide

Published guide:
https://josemandrade.github.io/prueba-his-muse-nvidia/derivacion-aps-especialidad/

Implementation Guide (FHIR R4) for the referral of a patient from
primary care (APS) to a specialty, with counter-referral back to APS.
Built with SUSHI (FSH) from `input/fsh/`; 12 profiles, 14 extensions,
8 CodeSystems, 8 ValueSets, 31 examples. Validated with SUSHI (0 errors
/ 0 warnings) and the FHIR IG Publisher.

## Build

- `sushi .` (needs fsh-sushi installed)
- `java -Xms3550m -Xmx3550m -jar publisher.jar -ig .` (needs Java 17 + Jekyll; in CI this
  runs in `.github/workflows/ig-build-referral.yml`)
- The publisher output goes to `output/`; the QA report is `output/qa.tgz`.

## Contents

- `sushi-config.yaml` — guide id and canonical (the published URL above).
- `input/fsh/` — profiles, extensions, ValueSets, CodeSystems, examples.
- `input/pagecontent/` — the guide's pages (index, profiles, operations,
  mapping, terminology, IHE, lifecycle, rules, sequences, process,
  public-health, resources).
- `fsh-generated/` — resources generated by SUSHI (do not edit by hand).
- `plan.md` — the step 5 task plan; `validation-report.md` — the
  validation results.
