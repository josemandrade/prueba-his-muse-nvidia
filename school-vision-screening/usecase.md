## Clinical Use Case

### Clinical Use Case: School Vision Screening

-------

#### Problem Statement

Vision problems in schoolchildren go undetected until they affect learning. The school nurse screens visual acuity per eye during the school year. Children with abnormal results must be referred to an ophthalmologist, the result must reach the primary care team for the health record, and parents must be notified. Today this is paper-based and referrals get lost — there is no feedback loop from ophthalmology back to the school or primary care.

-------

#### Users, Roles, and Departments

| | | | | |
| :--- | :--- | :--- | :--- | :--- |
| School Nurse | School Health Service | Screens visual acuity, records results, generates referral letter, notifies parent, tracks referrals, follows up on overdue/absent/incomplete/DNA | Child identity, screening data, referral status, ophthalmology feedback | Pass / refer per eye; whether to refer; re-screening; re-referral; closure |
| Child (Patient) | School | Participates in screening | Own experience | N/A |
| Parent / Guardian | Family | Receives notification, consents (opt-out), takes child to ophthalmologist, responds to nurse follow-up | Screening result letter or referral letter | Whether to opt out; whether to attend referral; whether to accept re-referral |
| Ophthalmologist | Eye Clinic / Hospital | Performs assessment, provides diagnosis, prescription, follow-up plan | Referral letter, child identity, screening results | Diagnosis, prescription, follow-up plan, outcome (seen / DNA) |
| Primary Care Team | General Practice / Community Health | Receives screening result and ophthalmology assessment for health record | Full screening + assessment data (when received) | Clinical record continuity, future care decisions |
| Teacher | School | Receives accommodation notice only | Accommodation (glasses needed, front seat) — never acuity values | Classroom seating, awareness of needs |

-------

#### Data Flow Summary

##### Screening (Nurse → Record)

* **Input:** Child identity (name, DOB, school roll number, grade/class), screening date, screener name, test used (Snellen 6m / Tumbling E / Lea symbols), right eye acuity, left eye acuity
* **Decision logic:** Pass if ≥6/9 each eye; Refer if ≤6/12 either eye OR ≥2 line difference between eyes
* **Outcomes:** 
* **Pass** → parent notification (pass letter), record held by nurse
* **Refer** → referral path
* **Absent** → re-screen within 2 weeks same school year; if still absent → record as missed, notify parent, do not refer to primary care
* **Incomplete** (e.g., uncooperative, one eye only) → record as incomplete with reason, re-screen within 2 weeks; if 2nd attempt still incomplete → direct referral to ophthalmology with partial result noted
 

##### Referral (Nurse → Parent → Ophthalmologist)

* Referral letter printed, given to parent, copy retained with screening record in school file
* Carries: child name, DOB, school/grade, screening date, acuity per eye, test used, reason for referral, screener name/contact
* Parent may **decline referral** → primary care still receives screening result; decline recorded with reason; referral not sent
* Nurse tracks referral sent date; expected turnaround **4 weeks** from referral to assessment return
* If no return in 4 weeks → nurse contacts parent to check appointment status, re-issues referral if lost

##### Ophthalmology Assessment (Ophthalmologist → Parent → School Nurse / Primary Care)

* **Output:** Diagnosis (myopia, hyperopia, astigmatism, amblyopia, etc.), refractive prescription, follow-up plan (review interval, treatment e.g. patching), outcome (seen / did not attend / DNA)
* **DNA outcome:** nurse contacts parent, offers **one re-referral** with new appointment; if child does not attend twice → close referral as DNA, notify primary care
* **Desired flow back:** 
* To school nurse: diagnosis + prescription summary (for accommodation: glasses, front seat)
* To primary care team: full assessment for health record
 

##### Primary Care Receive

* Receives: screening result (pass/refer/absent/incomplete/declined) + ophthalmology assessment when available
* Entered in child's health record

##### Teacher Accommodation

* Generated by nurse from ophthalmology feedback when received
* Contains only: accommodation needed (glasses, front seat) — never acuity values or diagnosis detail

-------

#### Consent and Legal Basis

* **Consent model:** opt-out at start of school year (parents informed, can decline screening)
* **No signed consent per child**
* **Referral consent:** separate from screening opt-out; parent may decline referral after screening
* **No legal mandate for reporting**
* **Program runs under school health program**
* **Opt-out is revocable mid-year** — parent can change mind at any time; statusHistory tracks all changes

-------

#### Data Governance

* Screening record held by school nurse
* Referral letter copy retained with screening record for school year, then archived together under school records policy
* Teachers see only accommodation (glasses needed, front seat) — never acuity values
* Records kept for school year, then archived under school records policy
* **No real patient data in this design** — synthetic data only for examples and tests
* **Demographic matching** (name, DOB, address) is primary PIXm strategy; national health ID optional supplementary identifier

-------

#### Success Criteria (Concrete Examples)

##### Normal Referral Path

**Scenario:** 8-year-old child, Grade 3, screened 2026-11-15

* Right eye: 6/12, Left eye: 6/9 → Refer (right eye ≤6/12)
* Nurse records screening, prints referral letter, sends parent notification
* Parent takes child to ophthalmologist 2026-11-22
* Ophthalmologist diagnoses: mild myopia OD, prescribes -1.00 DS OD, follow-up 12 months
* School nurse receives: "Myopia OD, glasses prescribed" → teacher informed: "needs glasses, front seat"
* Primary care receives: full assessment letter → entered in child's health record
* All steps traceable, no paper lost, nurse knows child was seen

##### Absent Child

Child absent 2026-11-15 → re-screen scheduled 2026-11-22 → child present, screened normally

##### Incomplete Screening

Child uncooperative, only left eye tested (6/9) → recorded incomplete, re-screen 2026-11-22 → still uncooperative → direct referral with "left eye 6/9, right eye untestable" noted

##### DNA (Did Not Attend)

Referred 2026-11-15, no return by 2026-12-13 → nurse contacts parent → re-referral 2026-12-20 → child DNA again 2027-01-10 → close as DNA, notify primary care

##### Decline Referral

Screened 2026-11-15, refer indicated → parent declines referral → screening result + decline reason sent to primary care; no referral letter sent

##### End-of-Year Missed

Child has pending re-screen at end of school year → recorded as missed, parent notified, primary care notified for follow-up outside school program
