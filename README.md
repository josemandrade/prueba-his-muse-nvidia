# prueba-his-muse-nvidia

Test repository for real-harness case builds with
[health-interop-superpowers](https://github.com/josemandrade/health-interop-superpowers)
(v0.39.0), a skill pack for health-data interoperability (FHIR R4 / HL7 v2 /
SNOMED CT / LOINC / ICD-10).

## Cases

- `docs/health-interop/2026-11-19-referral-aps-especialidad/` — Referral from
  primary care (APS) to a specialty, with counter-referral; full 6-step case
  documentation (spec, BPMN, entities, FHIR proposal, Implementation Guide,
  component).
- `docs/health-interop/2026-11-19-school-vision-screening/` — School vision
  screening; full 6-step case documentation.

All clinical data in these cases is synthetic. No real patient data.
